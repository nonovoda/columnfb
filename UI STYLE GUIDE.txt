# UI STYLE GUIDE — FB TOOLING

Создавай интерфейсы в стиле минималистичных внутренних инструментов для Facebook Ads Manager.

Главный ориентир:

* чистый dark UI;
* минимальный визуальный шум;
* высокая читаемость;
* ощущение internal utility tool;
* спокойный premium-tech стиль без «киберпанка».

Интерфейс должен выглядеть функционально, а не декоративно.

---

# ВИЗУАЛЬНЫЙ СТИЛЬ

Основа интерфейса:

* тёмный matte background;
* очень мягкие зелёные акценты;
* тонкие границы;
* минимальные glow-эффекты;
* почти полное отсутствие теней;
* flat/minimal surfaces.

НЕ использовать:

* glassmorphism;
* сильные blur;
* яркие свечения;
* сложные градиенты;
* тяжёлые тени;
* oversized UI;
* «геймерский» стиль.

# ТИПОГРАФИКА

Использовать максимум 2 шрифта.

## Основной шрифт интерфейса

* Inter

Использовать вариативность только через:

* font-weight;
* opacity;
* size.

## Заголовки

* weight: 700–800;
* цвет: accent green;
* компактные;
* без огромных размеров.

## Основной текст

* weight: 400–600;
* высокая читаемость;
* плотный UI без лишнего воздуха.

---

# ЯЗЫК ИНТЕРФЕЙСА

Интерфейс всегда на русском языке.

На английском допустимо:

* названия инструментов;
* бренды;
* технические названия.

Все:

* кнопки;
* статусы;
* helper text;
* placeholders;
* onboarding;
* уведомления;

должны быть на русском.

---

# КОМПОНЕНТЫ

## Модалки

* width: 420–460px;
* компактные;
* аккуратная вертикальная структура;
* минимальные внутренние отступы;
* без сложной композиции.

## Inputs / Selects

* тёмный flat background;
* тонкая зелёная граница;
* radius 8px;
* лёгкий accent при focus.

## Кнопки

Primary:

* тёмная кнопка;
* тонкая зелёная граница;
* зелёный текст;
* minimal hover.

НЕ делать кислотные заливки.

## Списки

* flat style;
* компактные строки;
* минимальные padding;
* высокая плотность информации.

---

# HOVER / ACTIVE STATES

Hover:

* лёгкое осветление background;
* чуть ярче border.

Active:

* лёгкое затемнение.

Disabled:

* muted text;
* reduced contrast.

Анимации:

* 150–200ms;
* только opacity/background/border.

---

# LAYOUT

Использовать:

* чёткую вертикальную структуру;
* grid/flex;
* ритмичные отступы;
* компактность;
* визуальную иерархию через контраст.

Избегать:

* лишних декоративных блоков;
* пустого пространства ради воздуха;
* сложных dashboard layouts.

---

# ОБЩИЙ ВАЙБ

Интерфейс должен ощущаться как:

* приватный internal tool;
* utility для media buyer;
* рабочий инструмент;
* минималистичная control panel.

Ключевые принципы:

* функциональность;
* скорость восприятия;
* минимализм;
* читаемость;
* единая айдентика между всеми скриптами.
