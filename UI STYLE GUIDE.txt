# UX/UI STYLE — FB BOOKMARKLET TOOLS

Создавай интерфейсы в стиле компактного внутреннего инструмента для Facebook Ads Manager.

## Общий принцип

Интерфейс должен быть не «красивым SaaS», а быстрым рабочим окном: маленькая модалка, понятные поля, один основной сценарий действия, лог выполнения и минимум визуального шума.

## Layout

* Модалка по центру экрана.
* Ширина: 420px.
* Максимальная высота: `calc(100vh - 40px)`.
* Внутренний скролл, если контента много.
* Отступы компактные: 8–14px.
* Структура сверху вниз: заголовок → настройки → действие → результат/лог → короткая заметка.

## Цвета

* Основной фон модалки: `#0f1715`
* Внутренние поля: `#121f1b`
* Лог/глубокий блок: `#0b1210`
* Основной текст: `#e8fff0`
* Вторичный текст: `#99b3a6`
* Label text: `#c7e0d2`
* Border: `#2b433a`
* Input border: `#2f4a40`
* Accent green: `#4dff8f`
* Success: `#9bff7d`
* Error: `#ff8f8f`

## Typography

* Один основной шрифт: `Inter, Segoe UI, Arial, sans-serif`.
* Базовый размер: 13px.
* Line-height: 1.4.
* Заголовок: 32px, font-weight 800, цвет `#4dff8f`.
* Labels: 12px, цвет `#c7e0d2`.
* Meta/notes: 11px, цвет `#99b3a6`.
* Лог: 12px, `white-space: pre-wrap`.

## Components

### Modal

* `position: fixed`
* centered через `left:50%; top:50%; transform:translate(-50%,-50%)`
* `z-index: 2147483647`
* border-radius: 14px
* border: `1px solid #2b433a`
* shadow: `0 24px 60px rgba(0,0,0,.45)`

### Header

* Заголовок слева.
* Версия под заголовком.
* Крестик закрытия справа сверху.
* Крестик без фона, только текстовый символ `×`.

### Inputs / Selects / Buttons

* Все элементы full-width.
* Radius: 9px.
* Border: `1px solid #2f4a40`.
* Background: `#121f1b`.
* Text: `#e8fff0`.
* Padding: 9px.
* Multiple select: min-height 110px.

### Primary Button

* Background: `#4dff8f`.
* Text: `#052012`.
* Border: `#4dff8f`.
* Font-weight: 700.
* Использовать только для главного действия.

### Secondary Button

* Background: `#121f1b`.
* Text: `#e8fff0`.
* Border: `#2f4a40`.

### Log

* Background: `#0b1210`.
* Border: `1px solid #22372f`.
* Radius: 10px.
* Padding: 8px.
* Max-height: 180px.
* Scrollable.
* Success строки зелёные.
* Error строки красные.

## UX Rules

* Все тексты интерфейса на русском.
* Английский допустим только в названии инструмента.
* Основной сценарий должен быть очевиден без инструкции.
* У каждого долгого действия должен быть лог.
* Кнопки во время выполнения нужно блокировать.
* Ошибки писать прямо в лог, не только через alert.
* Состояние результата должно быть копируемым одной кнопкой.
* Если скрипт уже открыт — повторный запуск должен закрывать окно.

## Что не использовать

* Glassmorphism.
* Большие градиенты.
* Сильный neon glow.
* Лишние декоративные карточки.
* Сложную сетку.
* Огромные отступы.
* Английские UI-тексты.
* Несколько визуальных стилей внутри одного скрипта.
